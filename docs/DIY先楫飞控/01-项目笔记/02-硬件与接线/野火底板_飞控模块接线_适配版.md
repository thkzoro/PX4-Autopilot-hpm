# 野火底板飞控模块接线（适配版）

本文档对应当前已修改的 `boards/px4/fmu-v6xhpm` 配置，目标是方便使用杜邦线在野火 `HPM6750IVM2-BTB` 底板上做飞控模块调试。

当前资源分配：

- GPS: `UART2.D`
- ELRS RP3: `UART11.D`（CRSF）
- 数传: `UART12`（TEL1 / MAVLink）
- IMU: `SPI2`
- SPL06: `I2C3`
- IST8310: `I2C3`
- 蜂鸣器: `PB19`（J5-44）
- PWM 输出: `PE02 / PE07 / PE06 / PE03`

## 1. GPS 模块 BZ-251（M10 + IST8310）

### GPS 串口

| 模块引脚   | 连接到底板                       |
| ------ | --------------------------- |
| GPS TX | J5-20 (`PY09`, `UART2_RXD`) |
| GPS RX | J5-19 (`PY08`, `UART2_TXD`) |
| 3.3V   | J5-1                        |
| GND    | J5-3 或 J5-4                 |

### IST8310 罗盘

| 模块引脚 | 连接到底板 |
| --- | --- |
| SCL | J5-6 (`PF10`, `I2C3_SCL`) |
| SDA | J5-11 (`PY05`, `I2C3_SDA`) |
| 3.3V | J5-1 |
| GND | J5-3 或 J5-4 |

## 2. IMU 模块 ICM42688P

当前适配版把 ICM42688P 放在 `SPI2`。

注意：

- `PB24 (J5-40)` 已经被板上 SPI flash 用作 CS
- 不要把 IMU 的 CS 接到 `J5-40`
- 适配版里把 IMU 的 CS 放到 `PB16 (J5-33)`，这是普通 GPIO 片选

接线如下：

| 模块引脚 | 连接到底板 |
| --- | --- |
| SCK | J5-42 (`PB21`, `SPI2_SCLK`) |
| MISO | J5-39 (`PB25`, `SPI2_MISO`) |
| MOSI | J5-10 (`PB22`, `SPI2_MOSI`) |
| CS | J5-33 (`PB16`, GPIO) |
| INT/DRDY | J5-35 (`PD19`, GPIO/中断) |
| 3.3V | J5-1 |
| GND | J5-3 或 J5-4 |

## 3. 气压计 SPL06-001

当前适配版把 SPL06 放在 `I2C3`，与 IST8310 共用总线。

| 模块引脚 | 连接到底板                      |
| ---- | -------------------------- |
| SCL  | J5-6 (`PF10`, `I2C3_SCL`)  |
| SDA  | J5-11 (`PY05`, `I2C3_SDA`) |
| 3.3V | J5-1                       |
| GND  | J5-3 或 J5-4                |

## 4. ELRS RP3 接收机

当前适配版按 `CRSF` 使用，不走 `SBUS`。

也就是说：

- `SBUS` 可以不用
- `RC_SERIAL_SINGLEWIRE` 已移除
- 接收机按全双工 UART 接线

接线如下：

| 模块引脚 | 连接到底板 |
| --- | --- |
| RP3 TX | J5-21 (`PZ04`, `UART11_RXD`) |
| RP3 RX | J5-17 (`PZ05`, `UART11_TXD`) |
| 5V | J5-2 |
| GND | J5-3 或 J5-4 |

说明：

- `RP3` 用 `CRSF`
- PX4 仍然保留 `SBUS` 支持，但这套接线不需要 `SBUS`

## 5. PM02 电源模块

当前适配版已经把 PM02 模拟采样改到 `J5`：

| PM02 引脚 | 连接到底板 |
| --- | --- |
| 5V 输出 | J5-2 |
| GND | J5-3 或 J5-4 |
| VOLT | J5-29 (`PE21`, `ADC0_VINP7`) |
| CURR | J5-30 (`PE25`, `ADC0_VINP11`) |

说明：

- `VOLT`、`CURR` 都是模拟量，必须和底板 `GND` 共地
- HPM6750 ADC 输入范围是 `0~3.3V`，不要把电池原始电压直接接进 `J5-29/J5-30`
- `PM02` 这种 Pixhawk 电源模块本身已经做了分压/采样输出，适合接这两个 ADC 脚
- 上板后还需要在 PX4 里按你的 PM02 实物标定 `BAT1_V_DIV` 和 `BAT1_A_PER_V`

当前代码里为了让开发板通过预检，`system_power` 按“USB 供电调试板”方式发布。
这适合你现在的杜邦线联调；如果后面做正式飞控硬件，建议再补真实 5V rail sensing。

## 6. 数传（MAVLink / TEL1）

当前适配版给野火底板单独留了一组数传口：

| 模块引脚 | 连接到底板 |
| --- | --- |
| 数传 TX | J5-26 (`PC20`, `UART12_RXD`) |
| 数传 RX | J5-23 (`PE01`, `UART12_TXD`) |
| 5V | J5-2 |
| GND | J5-3 或 J5-4 |

说明：

- 这组串口在 PX4 里是 `TEL1 = /dev/ttyS12`
- 当前 `rc.board_mavlink` 已默认在这组口上启动 `MAVLink`
- 默认波特率按常见数传模块先给了 `57600`
- 默认模式是 `onboard_low_bandwidth`，更适合 SiK/433/915MHz 这类透明串口数传

## 7. PWM 输出（450 机架四轴）

当前适配版 4 路 PWM 输出为：

| 电机通道 | 底板引脚 |
| --- | --- |
| PWM1 | J5-34 (`PE02`) |
| PWM2 | J5-22 (`PE07`) |
| PWM3 | J5-38 (`PE06`) |
| PWM4 | J5-8 (`PE03`) |

建议接法：

- 这 4 路只接 ESC 的信号线
- ESC 地线要和底板地共地
- ESC/BEC 供电建议仍然由 PM02/电源模块统一处理

## 8. 蜂鸣器

当前适配版已经把蜂鸣器改到 `J5` 上，便于你在野火底板上直接外接模块：

| 模块引脚 | 连接到底板 |
| --- | --- |
| 蜂鸣器信号 | J5-44 (`PB19`, `PWM1.P0`) |
| GND | J5-3 或 J5-4 |

说明：

- 当前 PX4 仍然使用 `tone_alarm`
- 板载 `rgbled_pwm` 已停止自动启动，释放 `PB19`
- 这根脚原始复用也是 `CAN1_TXD`，如果后面要用 `CAN1`，需要重新分配
- 如果你接的是有源蜂鸣器模块，通常接 `SIG + 5V + GND`
- 如果你接的是无源蜂鸣器/压电片，建议中间加驱动级，不要直接重载 MCU 引脚

## 9. 备注

如果你后续要继续扩展：

- CAN：当前适配版没动
- 电池采样：当前适配版没动
- USB/QGC：已在上一轮 bootloader/运行态 USB 改造里完成基础支持
